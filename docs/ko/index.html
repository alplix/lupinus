네이티브 VNC 및 RDP 원격 데스크톱 클라이언트

Mac에 내장된 화면 공유를 포함해 모든 VNC 또는 RDP 컴퓨터에 작고 빠른 네이티브 앱 하나로 연결하세요. 브라우저 탭도, Electron도 필요 없습니다.

Lupinus 다운로드 다른 플랫폼 GitHub에서 보기

무료 오픈 소스 · Windows · macOS · Linux

필요한 것은 모두, 불필요한 것은 없이

VNC와 RDP를 한 앱에서

Raw, CopyRect, ZRLE, Tight 인코딩을 지원하는 VNC, 그리고 NLA 로그인과 TLS 인증서 고정을 지원하는 RDP.

Mac 화면 공유와 호환

Mac 사용자 이름과 암호로 로그인하세요. Mac에 별도 소프트웨어가 필요 없습니다.

느린 회선에서도 빠르게

색 심도가 연결 상태에 맞게 조정되고 변경된 픽셀만 그려서, 먼 거리 세션도 쾌적하게 사용할 수 있습니다.

여러 세션 동시 사용

여러 컴퓨터를 열어 두고 즉시 전환하세요. 끊긴 연결은 자동으로 다시 연결됩니다.

깔끔한 정리

색상 태그, 빠른 연결, 저장된 연결 가져오기 및 내보내기.

설계부터 프라이빗

암호는 설정 파일이 아닌 OS 키체인에 저장됩니다.

클립보드와 키

양방향 클립보드 동기화, 완전한 키보드 전달, Ctrl+Alt+Del 버튼.

사용자의 언어로

오른쪽에서 왼쪽으로 쓰는 언어를 포함한 38개 언어를 자동으로 선택합니다.
