ネイティブな VNC / RDP リモートデスクトップクライアント

Mac 内蔵の画面共有を含め、あらゆる VNC・RDP マシンに、小さく高速なネイティブアプリ 1 つで接続できます。ブラウザのタブも Electron も不要です。

Lupinus をダウンロード その他のプラットフォーム GitHub で見る

無料・オープンソース · Windows · macOS · Linux

必要なものだけを、すべて

VNC と RDP を 1 つのアプリで

Raw・CopyRect・ZRLE・Tight エンコーディングに対応した VNC と、NLA サインインおよび TLS 証明書のピン留めに対応した RDP。

Mac の画面共有に対応

Mac のユーザー名とパスワードでサインイン。Mac 側に追加のソフトウェアは不要です。

低速回線でも快適

色深度が回線に合わせて自動調整され、変化したピクセルだけを描画するので、遠距離のセッションでも実用的です。

複数セッションを同時に

複数のマシンを開いたまま瞬時に切り替え。切断された接続は自動で再接続します。

すっきり整理

カラータグ、クイック接続、保存済み接続のインポートとエクスポート。

設計からプライベート

パスワードは設定ファイルではなく、OS のキーチェーンに保存されます。

クリップボードとキー

双方向のクリップボード同期、完全なキーボード転送、Ctrl+Alt+Del ボタン。

あなたの言語で

右から左に書く言語を含む 38 言語を自動で選択します。
